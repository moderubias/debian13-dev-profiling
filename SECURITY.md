# Security policy

This project generates candidate hardening files and contains an experimental, explicitly installed host-input firewall transaction engine. The general hardening modules remain unapplied. Network changes require independent recovery access, a reviewed plan, and timely confirmation. The current slice is not certified for production deployment; see docs/network.md for its scope, prerequisites, supported layouts, and recovery limitations.

Security concerns should be reported privately to the maintainer instead of publishing unpatched exploitable details. No vulnerability reporting contact has been designated yet; configure GitHub private vulnerability reporting when publishing the repository.

The project cannot defend against volumetric DDoS that saturates an upstream link and cannot replace software security testing, backups, incident response, or provider-level protection.
